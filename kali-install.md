# Installing Kali Linux in VirtualBox

**Goal:** Set up a Kali Linux practice machine.

**What I did:**
- Created a virtual machine in VirtualBox
- Attached the Kali installer ISO
- Set memory to 4 GB and chose Debian (64-bit)
- Ran the graphical installer, chose "Guided - use entire disk" on the 26.8 GB virtual disk
- Kept the default Xfce desktop and tools

**What went wrong:**
- I first chose the speech installer by mistake, so Kali read the screen aloud
- I accidentally lost the partition option and had to go back
- I couldn't change the time zone to Nigeria (command not found), so I left it for later

**What I learned:**
- A virtual machine lets me practise safely, since it can't harm Windows
- "Use entire disk" only means the virtual disk, which I checked by reading the size
- Read each screen before pressing Enter

**Security link:** Isolating practice machines (the Week 1 idea of prevent, detect, correct) keeps mistakes away from real systems.
