# Linux First Commands

**Goal:** Run basic Linux commands on Ubuntu.

**What I did:** Installed Ubuntu on Windows, created a folder with mkdir, moved in with cd, wrote a file with echo, and read it back with cat.

**What I learned:**
- Linux paths use / and Windows paths use \
- The root account has full power, so a typo can do real damage
- "command not found" usually means a typo, like "is" instead of "ls"

**Security link:** Week 2 taught that the kernel can touch anything, so everyday work should use the least power needed.
